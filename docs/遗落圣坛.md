# 石址：常驻刷怪地图

目标平台为 Purpur 26.2-2633、Java25、MythicMobs5.13.0、CraftEngine26.9.2。Dungeon仍使用provided Paper1.21.11 API，隔离Purpur26.2已验证启动；不声明Folia实测兼容。

## 使用

完整重启载入新Dungeon JAR和MythicMobs定义后，使用 `/dungeon enter lost_altar` 单独进入共享地图；每名玩家均可自行进入，无队长、门票、剧情、阶段或通关奖励。`/dungeon exit` 返回既有副本大厅，普通权限统一 `dungeon.use`。大厅必须可用才可通过该命令离开；也可使用服务器原有回城指令。

怪物、技能、掉落均在服务器 `plugins/MythicMobs/`。地图归档和manifest只在 `plugins/Dungeon/maps/lost_altar/`，不打入插件JAR。Dungeon检查DataVersion和逐文件SHA256后，沿用已有PermanentMapInstaller将地图注册到主世界的 `dimensions/minecraft/lost_altar`，永久地图不会进入临时实例清理。地图碰到非本插件归属标记的已有目录会拒绝覆盖。源存档未修改；导入副本不带玩家/旧实体数据。30,592个区块完成离线检查，原地图无命令方块/刷怪笼/箱子战利品需要删除（计数均0）。

## 掉落

每条独立概率，数量可直接在掉落表调整；均由 `dungeonce{id=命名空间:物品}` 调用CE注册物品，不用重命名原版物品冒充。

| 物品 | 普通怪 | 精英怪 |
|---|---|---|
| 初级升级单元 | 7%，1 个 | 30%，1–2 个 |
| 铁片、铁环 | 各 8%，1 个 | 各 16%，1 个 |
| 铜丝、普通燃料 | 各 4%，1 个 | 各 8%，1 个 |
| 铁架 | 各 3%，1 个 | 各 6%，1 个 |
| 合金 | 2%，1 个 | 4%，1 个 |
| 铜币 | 100%，1–3 个 | 100%，1–3 个 |
| 银币 | 无 | 10%，1 个 |

能量石、魔力碎片、远古核心和晶片不在石址掉落池中。

升级单元沿用机器实际配方，单台圆石生成器Lv.1→5共需2+6+16+40=64个。这里是持续产出渠道，不直接掉机器、收集器或绑定工具。铜币/银币为现有实体货币，不直接入账。掉落落地，由玩家拾取；不是个人包裹或按参与人数复制奖励。当前只对MythicMobs死亡归因中的玩家来源发放；环境击杀无掉落。实际每小时收益需用玩家击杀效率校准，当前数值为首版。

## 出生安全区

进入与死亡复活统一到管理员指定坐标 `-130.406, 7, 177.232`（yaw 127.3、pitch -3.2），已核对脚下实心地面和头部净空。安全区包含 X -164～-124、Z 155～186、Y 0～24 的方块范围，区内禁刷并免伤，出入发送语言文件通知。高度覆盖入口地面及上方空间，未使用选区时的临时高度。取消旧出生点圆形安全区，区外正常战斗。

Dungeon 在死亡时记录重生归属，直到 PlayerRespawnEvent 的 MONITOR 阶段才消费记录；DreamSkyblock 检测该记录后不创建或继续回岛会话，解决异步重生回岛覆盖副本位置的问题。两个 JAR 均需完整重启后加载。安全区与通知由 Dungeon 统一实现，不依赖 WorldGuard，避免两套范围不一致。
