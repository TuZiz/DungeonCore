# 石址：常驻刷怪地图

目标平台为 Purpur 26.2-2633、Java25、MythicMobs5.13.0、CraftEngine26.9.2。Dungeon仍使用provided Paper1.21.11 API，隔离Purpur26.2已验证启动；不声明Folia实测兼容。

## 使用

完整重启载入新Dungeon JAR和MythicMobs定义后，使用 `/dungeon enter lost_altar` 单独进入共享地图；每名玩家均可自行进入，无队长、门票、剧情、阶段或通关奖励。`/dungeon exit` 返回既有副本大厅，普通权限统一 `dungeon.use`。大厅必须可用才可通过该命令离开；也可使用服务器原有回城指令。

怪物、技能、掉落均在服务器 `plugins/MythicMobs/`。地图归档和manifest只在 `plugins/Dungeon/maps/lost_altar/`，不打入插件JAR。Dungeon检查DataVersion和逐文件SHA256后，沿用已有PermanentMapInstaller将地图注册到主世界的 `dimensions/minecraft/lost_altar`，永久地图不会进入临时实例清理。地图碰到非本插件归属标记的已有目录会拒绝覆盖。源存档未修改；导入副本不带玩家/旧实体数据。30,592个区块完成离线检查，原地图无命令方块/刷怪笼/箱子战利品需要删除（计数均0）。
