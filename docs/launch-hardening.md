# 石址上线保护验证

2026-11-11：安全区禁止玩家造成伤害，攻击性投射物不能从区内发射；伤害回调只读取玩家事件更新的线程安全状态，不跨 Folia 区域读玩家位置。

Dungeon 的 `dungeonce` 掉落归 MM 判定的击杀玩家优先拾取 30 秒，阻止其他生物、玩家、漏斗拾取以及保护期物品合并。归属放在地面物品实体上，拾取后的物品不带临时标签，可以正常堆叠；归属及到期时间随实体保存。普通丢弃物不锁定，不增加队伍或贡献分配规则。独立 `drop-protection.yml` 调整 0–300 秒，完整重启生效。

地图保护新增桶、火、踩耕地、实体破坏、装饰实体修改、实体及方块容器访问和自动物品转移限制。保留门、按钮及插件虚拟菜单。

刷怪上限以玩家为中心，候选点单独保存；预留中的怪物也参与统计。空间网格及玩家计数取代每次全表统计，移动、删除、失败预留及关闭均释放索引；HUD 使用范围查询。现有每人 10、附近 16、每人精英 1、附近精英 2 不变。

铜币普通/精英均为 80% 概率、1–3 个；精英银币仍为 10% 概率、1 个。材料概率不变。若 MM 数量 1–3 均匀分布，每杀期望铜币 1.6 个。30 分钟收益取决于实际击杀量：100/200/300 杀对应期望 160/320/480 铜币；100 只精英期望 10 银币。这是数学估算，不是实测经济收益。

验证：Maven package 与当前 38 测试通过；100 名模拟玩家、1000 条怪物记录、10000 次空间查询及并发移动/回收通过，单次本地 JVM 统计测试约 12.7ms。不能作为真实玩家容量或 TPS 证明。

隔离 Leaf 26.3 + Java 25 + MM 5.14 + CE 26.9.2，真实 MM 掉落 SPI 与 CE 物品落地、归属/到期/漏斗/合并/环境击杀、攻击/免伤/投射物出生位置、桶/点火/耕地/容器及区外战斗、虚拟菜单对照通过。玩家为代理、事件为探针构造；未进行真实客户端联机、Folia/Canvas/Arbor 运行压测或长时间掉落堆积测试。探针及脚本在 `tools/LaunchProbe.java`、`tools/verify_launch.py`。

上线前完整重启，再用两名真实玩家确认拾取保护、安全区进出战斗和副本死亡复活；观察目标在线人数下 TPS/MSPT、怪物数和地面物品数。隔离服存在原有 OSHI Windows 计数器警告；构建有原有 Unsafe/SQLite native-access/SLF4J 警告，均未阻止本次验证。
